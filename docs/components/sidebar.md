# EvSidebar

> The sidebar is the vertical navigation rail along the edge of an app, holding the brand, search, primary navigation items, and the user account. It can expand or collapse on desktop and appears as a slide-in drawer on mobile. Available for desktop (D) and mobile (M).

## Design guidance

From the Figma page **Sidebar**, frame `4446:84476` (Sidebar). These rules are binding. Names in them are Figma's - the Vue API is the tables above.

### When to use

- Use as the primary navigation for an app with many sections. Collapse it to icons (Open=No) to reclaim space on desktop; present it as a drawer on mobile.

### When not to use

- Don't use for a handful of top-level destinations — use a top navigation bar. Don't keep the mobile drawer permanently open over content.

### Do

- Group related items under section labels (USER, APPS). Keep the active item clearly highlighted. Preserve icon order between expanded and collapsed states.

### Don't

- Don't nest more than one level of sub-items. Don't hide the collapse control, and don't drop labels in the collapsed state without keeping recognizable icons.

## Design guidance

From the Figma page **Calendar & Time Picker**, frame `4218:66637` (Calendar & Time Picker). These rules are binding. Names in them are Figma's - the Vue API is the tables above.

### When to use

- Capture a date, date range, or time. Use the desktop Calendar for inline selection; on mobile use the Popup for compact fields or the Drawer for full-width bottom-sheet selection.

### When not to use

- A single known date that's faster to type. Avoid a Drawer on desktop or an inline Calendar on small mobile screens — match the picker to the breakpoint.

### Do

- Match the platform — D- for desktop, M- for mobile. Offer presets for common ranges, and provide a Reset to clear the selection.

### Don't

- Don't mix desktop and mobile variants in one breakpoint. Don't hide the selected value. Don't omit AM/PM where 12-hour time is expected.

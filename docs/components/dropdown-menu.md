## Design guidance

From the Figma page **Dropdown Menu**, frame `4262:77736` (Dropdown Menu). These rules are binding. Names in them are Figma's - the Vue API is the tables above.

### When to use

- Group related actions or commands behind a single trigger — row actions, overflow (⋯) menus, contextual commands, or account menus.

### When not to use

- To pick a value in a form → use a Dropdown List / Select. For primary page navigation → use a Nav, not an action menu.

### Do

- Order actions by frequency or group them with dividers. Add search for long menus. Use scroll affordances when the menu exceeds the viewport.

### Don't

- Don't mix destructive and routine actions without separation. Don't nest deep submenus. Don't exceed what fits without scroll.

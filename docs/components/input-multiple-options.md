## Design guidance

From the Figma page **Input**, frame `4715:10884` (InputMultipleOptions). These rules are binding. Names in them are Figma's - the Vue API is the tables above.

### When to use

- Use as the dropdown panel for a multi-choice selection.
- Use with InputMultipleField via its options slot.
- Use checkboxes so multiple rows can be selected.
- Use the active state to highlight the focused row.
- Use validation text to explain a selection constraint.

### When not to use

- Don't use for a single choice  →  use InputSingleOptions (`evoq-ui:input-single-options`).
- Don't use for free-form text  →  use InputField (`evoq-ui:input`).
- Don't show more options than are scannable without search.
- Don't hide how many items are selected.

### Do

- Show a checkbox state on every row.
- Keep option labels short and scannable.
- Reflect the selection count in the field.
- Make the whole row a toggle target.

### Don't

- Limit selection to one row.
- Use red styling without an explanatory message.
- Truncate labels so options become ambiguous.
- Disable the list without making the reason clear.

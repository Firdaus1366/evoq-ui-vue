## Design guidance

From the Figma page **Pagination**, frame `4410:83059` (Pagination). These rules are binding. Names in them are Figma's - the Vue API is the tables above.

### When to use

- Use to break long lists or tables into pages (Number / Display), or to step through a bounded sequence such as a wizard or onboarding flow (Step).

### When not to use

- Don't use for continuously streamed feeds — use infinite scroll or a "Load more" button (`evoq-ui:button`). Don't paginate very short lists that fit on one screen.

### Do

- Always show the current position and total. Keep Previous/Next reachable and disable them at the first/last page. Use the ellipsis (More L/R) to truncate long page ranges.

### Don't

- Don't show every page number for large sets — collapse the middle with an ellipsis. Don't mix Step and Number patterns in the same flow.

## Design guidance

From the Figma page **Button**, frame `3814:54536` (Button). These rules are binding. Names in them are Figma's - the Vue API is the tables above.

### When to use

- Use for the primary action in a form, card, dialog, or toolbar.
- Use one primary Button per view for the main action.
- Use Secondary / Outline / Ghost for lower-emphasis actions.
- Use Destructive for irreversible actions (delete, remove).
- Use Icon Only in dense toolbars where space is tight.

### When not to use

- Don't use to navigate between pages  →  use Link (`evoq-ui:button-link`)
- Don't use for an on/off setting  →  use Toggle (`evoq-ui:toggle`) / Switch (`evoq-ui:switch`)
- Don't use for many related options  →  use Segmented control
- Don't nest a Button inside another Button or Link.

### Do

- Use one clear primary action per view
- Keep labels to 1–3 words, sentence case, verb-first
- Use Destructive only for irreversible actions
- Provide an aria-label for Icon Only buttons

### Don't

- Place two primary Buttons side by side
- Write full sentences or ALL CAPS labels
- Use vague labels like “Submit” or “OK”
- Trigger destructive actions on the first click

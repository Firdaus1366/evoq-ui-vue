## Design guidance

From the Figma page **Input**, frame `4690:9331` (InputSingleOptions). These rules are binding. Names in them are Figma's - the Vue API is the tables above.

### When to use

- Use as the dropdown panel for a single-choice selection.
- Use with InputDropdown via its options slot.
- Use the active state to highlight the focused/selected row.
- Use validation text to explain a selection constraint.
- Use the disabled state when options are not selectable.

### When not to use

- Don't use for choosing multiple values  →  use InputMultipleOptions (`evoq-ui:input-multiple-options`).
- Don't use for free-form text  →  use InputField (`evoq-ui:input`).
- Don't show more options than are scannable without search.
- Don't allow more than one row to look selected.

### Do

- Highlight the currently selected row clearly.
- Keep option labels short and scannable.
- Show validation text close to the list, on error.
- Make the whole row a click target.

### Don't

- Allow more than one selected row at a time.
- Use red styling without an explanatory message.
- Truncate labels so options become ambiguous.
- Disable the list without making the reason clear.

## Design guidance

From the Figma page **Navigation Menu - Mobile**, frame `4347:82858` (Navigation Menu (Mobile)). These rules are binding. Names in them are Figma's - the Vue API is the tables above.

### When to use

- Use as the persistent bottom navigation on mobile for 2–5 primary destinations. Choose the Center Button variant when one action (create, scan, post) is clearly the primary task.

### When not to use

- Don't exceed 5 destinations — overflow belongs in a "More" menu. Don't use on desktop — use the desktop navigation bar. Don't put secondary actions in the center button.

### Do

- Keep labels to one word and pair each with a clear icon. Mark the active destination with the brand-blue icon and label. Keep the item count consistent across the app.

### Don't

- Don't hide the bar on scroll for core flows, and don't change the icon set or order between screens. Don't label the center action ambiguously.

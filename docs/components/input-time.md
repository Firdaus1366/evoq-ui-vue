## Design guidance

From the Figma page **Input**, frame `4690:5488` (Input Time). These rules are binding. Names in them are Figma's - the Vue API is the tables above.

### When to use

- Use to collect a time of day (e.g. hh:mm).
- Use the Small size in dense forms or tables.
- Use the time-picker slot for visual selection.
- Use validation text to guide correction inline.
- Use the disabled state when the time is not editable.

### When not to use

- Don't use for free-form text  →  use InputField (`evoq-ui:input`).
- Don't use for a calendar date  →  use InputDate (`evoq-ui:input-date`).
- Don't use for a duration if start/end need separate validation.
- Don't hide the expected time format from the user.

### Do

- Show the expected format (e.g. hh:mm) in the placeholder.
- Keep the clock icon visible as an affordance.
- Show validation text close to the field, on error.
- Use one consistent size within a form.

### Don't

- Rely on the placeholder alone as the label.
- Use red borders without an explanatory message.
- Mix Default and Small sizes in the same form.
- Disable a field without making the reason clear.

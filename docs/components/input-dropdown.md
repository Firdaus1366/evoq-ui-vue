# EvInputDropdown

> A select-style input with a trailing chevron that opens a list of options (slot). It comes in two sizes (44px and 36px), supports a leading icon and validation, and shares the same interaction states as InputField.

## Design guidance

From the Figma page **Input**, frame `4690:5935` (Input Dropdown). These rules are binding. Names in them are Figma's - the Vue API is the tables above.

### When to use

- Use to choose a single value from a fixed set of options.
- Use the Small size in dense forms or tables.
- Use a leading icon to signal the field's purpose.
- Use the options slot to mount the dropdown list.
- Use validation text to guide correction inline.

### When not to use

- Don't use for free-form text  →  use InputField (`evoq-ui:input`).
- Don't use for multi-select  →  use InputMultipleOptions (`evoq-ui:input-multiple-options`).
- Don't use for very long option lists without search  →  add a searchable list.
- Don't hide the chevron affordance.

### Do

- Keep option labels short and scannable.
- Keep the chevron visible as an open affordance.
- Show validation text close to the field, on error.
- Use one consistent size within a form.

### Don't

- Rely on the placeholder alone as the label.
- Use red borders without an explanatory message.
- Mix Default and Small sizes in the same form.
- Disable a field without making the reason clear.

## Design guidance

From the Figma page **Dropdown List**, frame `4258:77060` (Dropdown List). These rules are binding. Names in them are Figma's - the Vue API is the tables above.

### When to use

- Let users pick from a set of options without taking up persistent space — select fields, filters, action menus, or autocomplete suggestions.

### When not to use

- For 2–3 options that fit inline → use Radio (`evoq-ui:radio`) or a segmented control. For app navigation → use a Menu or Nav, not a data dropdown.

### Do

- Keep labels short and scannable. Add search (Combobox) for long lists. Enable scroll past ~7–8 items. Show a clear Not Found state for empty results.

### Don't

- Don't pack dozens of items without search or scroll. Don't mix unrelated actions and data options. Don't auto-select an item on hover.

## Design guidance

From the Figma page **Input**, frame `4690:6443` (Input Multiple Field). These rules are binding. Names in them are Figma's - the Vue API is the tables above.

### When to use

- Use to select multiple values from a set, shown as tags.
- Use a leading icon to signal the field's purpose.
- Use the options slot to mount the selectable list.
- Use validation text to guide correction inline.
- Use the disabled state when the selection is locked.

### When not to use

- Don't use for a single choice  →  use InputDropdown (`evoq-ui:input-dropdown`).
- Don't use for free-form text  →  use InputField (`evoq-ui:input`).
- Don't use when only one value is ever valid.
- Don't hide how to remove a selected tag.

### Do

- Make each tag removable with a clear close affordance.
- Wrap tags to a new line when they overflow.
- Show validation text close to the field, on error.
- Keep the chevron visible as an open affordance.

### Don't

- Rely on the placeholder alone as the label.
- Use red borders without an explanatory message.
- Truncate tags so the value becomes unreadable.
- Disable a field without making the reason clear.
